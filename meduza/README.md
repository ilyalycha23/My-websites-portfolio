# 🪼 Паб-бар Meduza

  <img src="readme-preview.jpg" alt="Превью сайта" width="720">

Пиво, кимчи, настолки, летняя веранда. Meduza — бар, в который возвращаются, а не «гастропаб с концепцией». Рейтинг 4,8, отметка «Хорошее место 2026».

## 🌙 Темнота, курсор и часы

Сайт не пытается быть светлым и «аппетитным». Тёмный холст, шум, подсветка, свой курсор, часы по Москве и живой статус «открыто / закрыто». Меню держит две линии сразу: пиво и корейская кухня — это и есть характер зала, а не случайный микс.

Бронь — звонок. Фотографии зала и веранды лежат в `code/assets/`.

## 🛠️ На чём сделан

Авторский лендинг на **HTML, CSS и JavaScript** (`app.js`). Шрифты Cinzel, Cormorant Garamond, Manrope. Без CMS. Время и акции завязаны на часовой пояс `Europe/Moscow`.

## ✨ Что реализовано

- Свой курсор и «прожектор», который едет за мышью; полоска прогресса скролла сверху.
- Часы в шапке и статус «открыто» с ночным переходом через полночь (в выходные до 02:00).
- **Акция дня** подставляется сама: понедельник — 1+1 на пиво, воскресенье — сет 450 ₽, и так по каждому дню.
- Подборка «пиво + блюдо» меняется, меню на вкладках, лайтбокс галереи.
- Тёмная кинематографичная вёрстка: шум, свечение, не сетевой «светлый паб».
