## 🎯 О проекте

Сайт бара **Meduza**. Свежее пиво, корейская кухня, настолки и летняя веранда. Рейтинг 4,8 на Яндекс Картах, «Хорошее место 2026».

### 💡 Основная идея
- Бар, в который хочется вернуться: пиво, кимчи, настолки
- Честная атмосфера района, без глянца сетевого паба
- Быстрая бронь по телефону и понятное меню

### ✅ Что есть на сайте
- Hero со статусом «открыто / закрыто» и часами
- О баре, акциях и атмосфере
- Меню: пиво, корейская кухня, закуски
- Фотогалерея зала и веранды
- Отзывы гостей
- Как дойти и бронь: +7 999 060-50-44

### 📱 Адаптивность
- 💻 Десктоп: тёмная кинематографичная подача и кастомный курсор
- 📱 Мобильная версия: меню, статус и звонок
- 🖼️ Оптимизация фото блюд и интерьера

## 🚀 Локальный запуск

```bash
cd code
python -m http.server 8080
```

Откройте `http://localhost:8080` в браузере.
