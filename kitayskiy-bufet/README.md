# 🍜 Китайский буфет

<p align="center">
  <img src="readme-preview.jpg" alt="Превью сайта" width="720">
</p>

Не агрегатор доставки и не «ещё одно азиатское кафе». Сайт собирает ощущение тихой китайской улочки: стрит-арт, красные фонари, большая порция, холодное китайское пиво. Обед −15% днём. Рейтинг 4,6.

## Меню как набор отдельных страниц

Это единственный проект в коллекции, где у блюд свои HTML-страницы, а не только карточки на главной. Данные меню живут в `code/js/menu-data.js`, сами позиции — в `code/menu/`. С главной можно уйти в том ям, гобаджоу или жоуцзямо и вернуться обратно.

Онлайн-корзины нет: сценарий — посмотрел, позвонил, пришёл.

## На чём сделан

Статический **HTML + CSS + JS**. Шрифты Manrope, Unbounded и Noto Serif SC (китайская каллиграфия в заголовках). Меню живёт в `menu-data.js`, карточки и страницы блюд собираются из одного массива. JSON-LD `Restaurant`.

## Что реализовано

- Отдельный HTML на каждое блюдо: вес, цена, описание, своё фото — как мини-карточка товара, только без корзины.
- Фильтр категорий на главной и кнопка «показать ещё»: сначала 8 позиций, потом всё меню.
- Индикатор «открыто до … / откроется в …» по дням недели (в пятницу и субботу дольше).
- Ленивая загрузка фото еды (`loading="lazy"`), чтобы длинное меню не душило телефон.

## 🚀 Локальный запуск

```bash
cd code
python -m http.server 8080
```

Откройте `http://localhost:8080` в браузере.
