# ☕ Сеть кофеен «Кусь»

## 🎯 О проекте

Сайт спешелти-кофеен **Кусь** в Санкт-Петербурге. Своя выпечка, завтраки до 15:00 и отдельное меню для собак. Три точки: Комендантский, Киришская и Среднерогатская.

### 💡 Основная идея
- Кофе «на районе», без поездки в центр
- Один вайб — три дома
- Дружелюбный тон бренда (кусь, хвосты, свой хлеб)

### ✅ Что есть на сайте
- Живой hero с приветствием по времени суток
- Меню кофе, выпечки и завтраков
- Отдельный блок «можно с хвостом» — меню для собак
- Фото залов
- Отзывы гостей
- Три адреса с часами и статусом «открыто»
- Бронь по телефону и Telegram

### 📱 Адаптивность
- 💻 Десктоп: характерная типографика и «билетная» навигация
- 📱 Мобильная версия: меню и адреса в один скролл
- 🖼️ Оптимизация фото блюд и интерьеров
