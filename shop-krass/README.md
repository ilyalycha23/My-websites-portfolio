# 👕 Сайт «SHOP КРАСС»

  <img src="readme-preview.jpg" alt="Превью сайта" width="720">
</p>

Бренд одежды про Краснодар: футболки и polo с авторскими принтами. Сайт выглядит как магазин, но корзины нет — это сознательно. Задача не продать онлайн, а показать коллекцию и собрать заявку.

## 🛍️ Магазин, который не продаёт в один клик

Каталог, состав, размеры, фото с разных ракурсов, история бренда и обратный звонок. Для локального мерча это честнее фейковой кнопки «купить», за которой нет доставки.

## 🛠️ На чём сделан

**WordPress**, кастомная витрина бренда. Не WooCommerce-магазин: покупка не через корзину, а через заявку. Код темы по запросу.

## ✨ Что реализовано

- Каталог футболок и polo с составом, размерами и фото с нескольких ракурсов.
- История и тон бренда «про Краснодар» — это имиджевый сайт, а не маркетплейс.
- Форма обратного звонка вместо онлайн-оплаты: лид, а не транзакция.
- Адаптивная сетка коллекции, чтобы принты читались и на телефоне.
