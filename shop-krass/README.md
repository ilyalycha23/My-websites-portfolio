# 👕 Сайт «SHOP КРАСС»

<p align="center">
  <img src="readme-preview.jpg" alt="Превью сайта" width="720">
</p>

Бренд одежды про Краснодар: футболки и polo с авторскими принтами. Сайт выглядит как магазин, но корзины нет — это сознательно. Задача не продать онлайн, а показать коллекцию и собрать заявку.

## Магазин, который не продаёт в один клик

Каталог, состав, размеры, фото с разных ракурсов, история бренда и обратный звонок. Для локального мерча это честнее фейковой кнопки «купить», за которой нет доставки.

WordPress-витрина. В папке — скриншот главной.
