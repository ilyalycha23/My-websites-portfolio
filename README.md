# 🚀 Коммерческие веб-проекты

Коллекция коммерческих веб-сайтов: корпоративные проекты на WordPress и авторские HTML-лендинги для локального бизнеса. Каждый проект создавался с учётом требований заказчика и современных стандартов веб-разработки.

## 📊 О проектах

Ранние работы — кастомизация WordPress: темы, плагины и индивидуальный дизайн. Более новые проекты — самостоятельная вёрстка на HTML, CSS и JavaScript: одностраничные сайты заведений с меню, галереей, отзывами и записью. Исходный код лендингов лежит в папке `code/` каждого проекта.
